# EXP-002 reproduction

Run from the repository root on a clean checkout of the recorded revision (see `run_manifest.json`).

```
../.tools/py/bin/uv sync --frozen --all-groups --all-extras
.venv/bin/python -m pytest
.venv/bin/python scripts/run_confirmatory.py EXP-002          # guard: clean tree, frozen hashes, raw data hash
.venv/bin/python scripts/analyse_confirmatory.py EXP-002      # tables, figures, frozen analysis -> generated/
cp research/experiments/EXP-002/generated/figures/*.svg research/experiments/EXP-002/figures/
cp research/experiments/EXP-002/generated/metrics.csv research/experiments/EXP-002/metrics.csv
cp results/confirmatory/EXP-002/run_manifest.json research/experiments/EXP-002/run_manifest.json
```

- Raw result file: `results/confirmatory/EXP-002/results.json` (schema `streak.result/1.0`, 31.8 MB, git-ignored, regenerated by the run command); SHA-256 in `results/confirmatory/EXP-002/sha256_manifest.json`.
- Provenance per run (id, config hash, seed, revision, data manifest hash, hardware, start and end, exit status): `results/confirmatory/EXP-002/provenance.json`.
- Expected: byte-identical `results.json` on the same platform with the same seeds and config (protocol section 8); identity across platforms was not tested (unverified).
- The raw Duolingo file is needed only for the run guard's data hash check; rebuild it with `scripts/download_duolingo.py` (SHA-256 in `data/manifest.json`).
