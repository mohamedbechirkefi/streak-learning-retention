# research/experiments/

One folder per registered experiment (see `../experiment_registry.csv`). At M0 each folder holds only a draft `protocol.md`; `report.md`, `config.json`, `run_manifest.json`, `metrics.csv`, `figures/` and `reproduction.md` are created when the experiment is implemented and run. No placeholder results are created.
